# Biomedical NER with BERT

Built a BERT-based Biomedical Named Entity Recognition (NER) model by fine-tuning bert-base-uncased on the BC5CDR dataset. The model identifies Chemical and Disease entities using BIO tagging and achieved an 81.3% F1 score on the test set, compared to a 0.53% baseline.

The project includes preprocessing with subword label alignment, model fine-tuning, evaluation, and interactive medical text prediction.
